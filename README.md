# 🎵 Clustering Music Genres

## 📌 Proje Hakkında  
Bu proje, müzik türlerini özelliklerine göre gruplandırmak için kümeleme (clustering) algoritmalarını kullanmaktadır.

## 🛠️ Teknolojiler  
Python, Pandas, NumPy, Matplotlib, Scikit-learn  

## 🎯 Amaç  
Benzer müzik türlerini veri özelliklerine göre gruplayarak anlamlı kümeler oluşturmak.  

## 📈 Sonuç  
Model, müzik türleri arasında benzerlikleri belirleyerek başarılı kümeler oluşturmuştur.
